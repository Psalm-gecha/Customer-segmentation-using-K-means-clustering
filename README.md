# Customer-segmentation-using-K-means-clustering
The project is a customer segmentation exercise using unsupervised learning (K-means clustering). It takes customer data (annual income and spending score) and groups individuals into clusters to reveal distinct spending and income patterns.
## 📌 Project Overview
This project demonstrates how businesses can apply unsupervised learning techniques to better understand their customers. Using the Mall_Customers dataset, the notebook applies K-Means clustering to group customers based on their annual income and spending score.

The goal is to identify distinct customer segments that can inform targeted marketing strategies and improve customer engagement.

## ⚙️ Methodology
Data Exploration

Load and preview the dataset (Mall_Customers.csv).

Select relevant features: Annual Income and Spending Score.

Elbow Method

Determine the optimal number of clusters by analyzing the Within-Cluster Sum of Squares (WCSS).

## K-Means Clustering

Apply K-Means with the chosen number of clusters.

Assign customers to clusters based on similarity.

## Visualization

Plot clusters to visually interpret customer segments.

## 🎯 Outcomes
Customers are grouped into distinct clusters that highlight differences in income and spending behavior.

These insights can be used to:

Identify high-value customers.

Tailor marketing campaigns.

Improve product recommendations.
